Сохранена вся функциональность v70:
- «Административные правки» вместо «Главный администратор»;
- администратор может удалять свои правки по проекту;
- администратор может удалять своё сообщение менеджеру;
- удаление фиксируется в истории;
- полная история проекта;
- история каждой галочки тезиса и блока;
- заметное сообщение менеджеру.

Для GitHub Pages замените старые файлы содержимым архива и сделайте Ctrl+F5.
