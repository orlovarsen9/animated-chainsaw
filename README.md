# Цитадель v55 — разное положение процента

Сделано два режима шкалы:

1. В списке «Мои проекты»
   - процент всегда виден справа в заголовке шкалы;
   - не нужно прокручивать список стадий, чтобы увидеть процент.

2. Когда открываешь сам проект
   - процент остаётся после самой последней стадии;
   - он двигается вместе со шкалой при горизонтальной прокрутке.

Apps Script обновлять не нужно.
