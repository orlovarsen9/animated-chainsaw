# Цитадель v60

В окне наблюдателя «Настройки менеджера» рядом с заголовком «Стадии проекта»
добавлена кнопка «Настройки менеджера».

По нажатию прямо в этом окне раскрываются:
- имя менеджера;
- логин;
- новый пароль;
- загрузка/замена картинки;
- удаление картинки;
- кнопка сохранения.

Используется backend updateManagerAccount из v58/v59.
Новая ссылка Apps Script из v59 сохранена.
