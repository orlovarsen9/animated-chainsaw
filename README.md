# Цитадель v66 — окончательное исправление GEO

Исправлена ситуация, когда в редакторе проекта выбрано «Классика»,
а в карточке проекта отображалось «Иное».

Причина была в том, что редактор и карточка могли читать разные старые поля GEO.

Теперь:
- карточка и открытый проект используют один общий GEO-резолвер;
- при сохранении значение GEO синхронизируется между старыми и новыми полями;
- старые проекты автоматически подхватывают правильное значение;
- `ru` нигде визуально не выводится.

Пример:
Классика + уточнение 77 → `Классика · 77`

Apps Script обновлять не требуется.
